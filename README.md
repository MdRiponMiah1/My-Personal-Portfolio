# 🌐 My Personal Portfolio

Welcome to my personal portfolio website.

This is a modern, responsive portfolio website built with **Django** to showcase my profile, skills, projects, and contact information.

The website also includes multiple themes and a smooth animated multi-color background for a more interactive and modern experience.

---

## ✨ Features

- 🏠 Home Page
- 👤 About Page
- 💼 Projects Page
- 📄 Project Details Page
- 📩 Contact Page
- 🎨 Multiple Themes
- 🌈 Animated Multi-Color Background
- ✨ Smooth Glow & Color Flow Effects
- 📱 Responsive Design
- 🗂️ Django Admin Panel
- 🗄️ SQLite Database
- ⚡ Clean Django Project Structure

---

## 🎨 Themes

My Personal Portfolio includes three different visual themes.

### 🌌 Midnight

A modern dark theme featuring:

- Purple
- Violet
- Pink
- Blue
- Magenta

### 🌊 Aurora

An aurora-inspired theme featuring:

- Cyan
- Blue
- Teal
- Green
- Violet

### 🤍 Minimal

A clean and professional light theme featuring:

- White Background
- Soft Blue
- Lavender
- Pink
- Mint
- Soft Yellow

The Minimal theme keeps the background clean and white while using subtle animated colors.

---

## 🌈 Animated Background

The portfolio includes a multi-color animated background system.

The background colors continuously:

- Move
- Blend
- Morph
- Glow
- Transition smoothly

The animation works across all major pages:

- Home
- About
- Projects
- Project Details
- Contact

Each theme has its own unique color combination.
